0x02 设置命令
=============

.. container:: doc-status

   **第一版本**　各 Key 的操作码、规则与具体命令示例。

.. _cmd-2-section-1:

命令格式
--------

以下为 L2 层命令格式，不含 L1 帧头。

.. list-table::
   :header-rows: 1
   :widths: 18 10 18 54
   :class: protocol-table command-format columns-4

   * - 字段
     - 长度
     - 取值
     - 说明
   * - Header
     - 2B
     - 02 00
     - ``02 00`` = Command 0x02，Version 0
   * - Key
     - 1B
     - —
     - 见第 2 节
   * - v-length
     - 2B
     - —
     - 操作码 1B + 数据长度
   * - 操作码
     - 1B
     - —
     - 见 1.2
   * - 数据
     - 可变
     - —
     - 见各 Key

* 多字节整数大端；字段按字节对齐（位图类除外）。写操作无 L2 回应（仅 L1 ACK）；读取超时默认 5s。一次一条消息只操作一个 Key。

.. _cmd-2-section-2:

操作码
------

.. list-table::
   :header-rows: 1
   :widths: auto
   :class: protocol-table columns-4

   * - 操作码
     - 方向
     - 操作数据
     - 说明
   * - ``0x00`` 设置
     - 手机 → 设备
     - 设置值
     - 整体覆盖，无回应
   * - ``0x01`` 读取
     - 手机 → 设备
     - 一般无；``0x61`` 带类型 1B；``0x91`` 带起始槽号 1B
     - 设备回 ``0x02``
   * - ``0x02`` 读取回应
     - 设备 → 手机
     - 当前值
     - 读不出则不回应
   * - ``0x03`` 通知
     - 设备 → 手机
     - 同设置/读取；列表型为变更类型 + 单条
     - 登录后上报，SDK 转发
   * - ``0x04`` 重置
     - 手机 → 设备
     - 无
     - 列表清空、天气清除
   * - ``0x05`` 新增
     - 手机 → 设备
     - 槽号 + 记录
     - 列表型
   * - ``0x06`` 删除
     - 手机 → 设备
     - 槽号 + 记录
     - 列表型
   * - ``0x07`` 修改
     - 手机 → 设备
     - 槽号 + 记录
     - 列表型

.. _cmd-2-section-3:

规则
----

1. **覆盖与读写**：普通项用「设置」整体覆盖。以 App/手机为准的项（时间 ``0x01``、手机系统 ``0x02``、用户资料 ``0x10``、女性健康 ``0x13`` 等）只支持设置、一般不读回；手表上也可改的项再加「读取」，重连后靠读取补齐断开期间的修改。
2. **列表型**（闹钟 ``0x60``、通讯录 ``0x91``、SOS ``0x92``）：增 / 删 / 改一次一条，槽号由 App 指定；支持读取与「重置」清全表。通讯录读取分页（带起始槽号），SOS 一次读全表。SDK 整表同步可封装为重置 + 逐条新增。
3. **回应与通知**：写操作（设置、增删改、重置）无 L2 回应，仅 L1 ACK；读取只回 ``0x02``，读不出则不回应。设备设置变更可发 ``0x03`` 通知（不区分手机/手表修改），列表型通知为变更类型 + 单条记录。参数非法或设备不支持时不生效，也可能无通知。
4. **时间段与扩展**：自动监测、告警、间隔提醒等带「时/分」起止，``起=终`` 表示全天，可跨天。健康监测 ``0x40～0x5F`` 每类占 4 个连续 Key（自动监测、告警、单位、保留）；单位只影响手表显示，协议数据与告警阈值用固定单位。Value 扩展只能在末尾追加，缺字段视为不支持。
5. **其它**：设备信息 ``0x30``、功能列表 ``0x31``、支持语言 ``0x33`` 只读；``0x34`` 设备控制只写，执行后约 1s 断连、无 L2/通知。天气 ``0x90`` 由 App 推送，关天气用重置。``0x24`` 表盘格式待定。语言编码见 HoneyProtocol 附表；第 2 节 v-length = 操作码 + 操作数据，「支持的功能」列括号内为操作码。

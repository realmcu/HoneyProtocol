0x0C BLE 连接参数命令
=====================

命令格式
--------

.. list-table:: L2 命令格式
   :header-rows: 1
   :widths: 18 10 18 54
   :class: protocol-table command-format columns-4

   * - 字段
     - 长度
     - 取值
     - 说明
   * - Header
     - 2B
     - 0C 00
     - ``0C 00`` = Command 0x0C，Version 0
   * - Key
     - 1B
     - 见规则
     - 请求与响应各一个 Key
   * - Length
     - 2B
     - Value 字节数
     - Big-Endian
   * - Value
     - 可变
     - 见具体命令
     - 请求为空，响应 7B

规则
----

* ``0x01`` 请求 Value 为空（Length = 0）。
* ``0x02`` Value 固定为 7 bytes，多字节字段使用 Big-Endian。

.. table:: BLE 连接参数返回字段

   +--------------------------+---------+--------------------------------------------------------------+
   | 字段                     | 大小    | 说明                                                         |
   +==========================+=========+==============================================================+
   | conn_interval            | 2 bytes | 当前连接间隔，单位 1.25ms（例：0x0018 = 24 × 1.25ms = 30ms） |
   +--------------------------+---------+--------------------------------------------------------------+
   | conn_latency             | 2 bytes | 从设备延迟（Slave Latency）                                  |
   +--------------------------+---------+--------------------------------------------------------------+
   | conn_supervision_timeout | 2 bytes | 监督超时，单位 10ms（例：0x01F4 = 500 × 10ms = 5000ms）      |
   +--------------------------+---------+--------------------------------------------------------------+
   | conn_mtu_size            | 1 byte  | 当前 ATT MTU 大小（字节）                                    |
   +--------------------------+---------+--------------------------------------------------------------+

具体命令
--------

.. list-table:: 协议数据示例
   :header-rows: 1
   :widths: 5 10 17 9 15 44
   :class: protocol-table command-detail columns-6

   * - Key
     - sub-key（操作码）
     - 名称 / 用途
     - 方向
     - 具体的命令
     - 数据说明
   * - 0x01
     - —
     - 请求连接参数 / 读取当前 BLE 参数
     - 手机 → 设备
     - ``0C 00 01 00 00``
     - Value 空（Length = 0）
   * - 0x02
     - —
     - 返回连接参数 / 7B 参数
     - 设备 → 手机
     - ``0C 00 02 00 07 00 18 00 00 01 F4 F7``
     - Interval 30 ms，Latency 0，Timeout 5000 ms，MTU 247

0x06 工厂测试命令
=================

.. container:: doc-status

   **草案**　具体命令表为 E_Tool 勾选且走 ``0x06`` 的 Key 全集（迁移自 HL §6）。E_Tool 中的点测、设置、固件/LE OTA、记录上传等 **不走本表**，见 :doc:`点测命令 <0x11-measurement>`、:doc:`设置命令 <0x02-settings>` 或 SDK/App 服务端。**非终版**。

.. _cmd-06-section-1:

命令格式
--------

.. list-table:: L2 命令格式
   :header-rows: 1
   :widths: 18 10 18 54
   :class: protocol-table command-format columns-4

   * - 字段
     - 长度
     - 取值
     - 说明
   * - Header
     - 2B
     - 06 00
     - ``06 00`` = Command 0x06，Version 0
   * - Key
     - 1B
     - —
     - 见 :ref:`具体命令 <cmd-06-section-3>`
   * - Length
     - 2B
     - —
     - Value 字节数（大端）
   * - Value
     - 可变
     - —
     - 见 :ref:`具体命令 <cmd-06-section-3>`

1. 多字节整数 **大端**；有符号字段、无效值（``FF`` / ``FFFF`` 等）见 :doc:`名词解释与约定 </conventions>`。
2. 本 Command 的 Value 一般不含 ``4B`` 墙上时钟；``0xF8`` 返回 5 组 ``8B`` Flash 读写地址，不是日历时间。若某 Key 含 ``4B`` 时刻，与 :doc:`数据命令 <0x05-data>` 相同（1970 起墙上时钟秒，大端）。

.. _cmd-06-section-2:

规则
----

各产测项彼此独立，无本 Command 级状态机；Key、方向与 Value 以下表为准。

.. _cmd-06-section-3:

具体命令
--------

.. list-table:: 协议数据示例
   :header-rows: 1
   :widths: 5 20 10 15 50
   :class: protocol-table command-detail columns-5

   * - Key
     - 名称 / 用途
     - 方向
     - 具体的命令
     - 数据说明
   * - 0x03
     - 电池电压请求 / F004
     - 手机 → 设备
     - ``06 00 03 00 00``
     - Value 空
   * - 0x04
     - 电池电压返回 / F004
     - 设备 → 手机
     - ``06 00 04 00 02 0B B8``
     - 2B 电压 mV（有符号，未检测到可为负）
   * - 0x20
     - Patch 版本请求 / F002、F031
     - 手机 → 设备
     - ``06 00 20 00 00``
     - Value 空
   * - 0x21
     - Patch 版本返回 / F002、F031
     - 设备 → 手机
     - ``06 00 21 00 04 …``
     - 4B：major/minor/revision/buildNum（见 HL §6.21）
   * - 0x22
     - Gsensor 请求 / F007
     - 手机 → 设备
     - ``06 00 22 00 00``
     - Value 空
   * - 0x23
     - Gsensor 返回 / F007
     - 设备 → 手机
     - ``06 00 23 00 09 …``
     - 9B：状态 1B + chip 1B + batch 1B + X/Y/Z 各 2B 有符号
   * - 0x26
     - 霍尔状态请求 / F013
     - 手机 → 设备
     - ``06 00 26 00 00``
     - Value 空
   * - 0x27
     - 霍尔状态返回 / F013
     - 设备 → 手机
     - ``06 00 27 00 01 00``
     - 1B：``00`` 舱内，``01`` 舱外
   * - 0x28
     - 产测默认功能写 / F049
     - 手机 → 设备
     - ``06 00 28 00 01 03``
     - 1B 位图：血压/温度/压力/场景/Alexa/光感/屏蔽老化入口等；bit7=1 关闭热应激
   * - 0x29
     - 马达长振 / 马达
     - 手机 → 设备
     - ``06 00 29 00 01 01``
     - 1B：``00`` 关，``01`` 开
   * - 0x2D
     - SN 读请求 / F024
     - 手机 → 设备
     - ``06 00 2D 00 00``
     - Value 空
   * - 0x2E
     - SN 读返回 / F024
     - 设备 → 手机
     - ``06 00 2E 00 …``
     - ≥2B SN（十六进制显示，长度由设备决定）
   * - 0x2F
     - 温度标定写 / 单台温度、F028
     - 手机 → 设备
     - ``06 00 2F 00 02 0E 4E``
     - 2B 标定温度（如 0.01℃ 单位，365=36.5℃ 见 HL）
   * - 0x30
     - 温度标定成功 / 单台温度、F028
     - 设备 → 手机
     - ``06 00 30 00 01 01``
     - 1B：``01`` 成功
   * - 0x31
     - 心率漏光检测开 / 漏光、F066
     - 手机 → 设备
     - ``06 00 31 00 01 01``
     - 1B：``01`` 开，``00`` 关；VC31/LC31 阈值由 App 判定
   * - 0x32
     - 心率漏光值 / 漏光、F066
     - 设备 → 手机
     - ``06 00 32 00 07 …``
     - 1B pass + ps/pre/current 各 2B（HL §6.32）
   * - 0x35
     - 写 MAC / F023、F029
     - 手机 → 设备
     - ``06 00 35 00 06 …``
     - 6B MAC
   * - 0x36
     - 写 MAC 结果 / F023、F029
     - 设备 → 手机
     - ``06 00 36 00 01 01``
     - 1B：``01`` 成功，``00`` 失败
   * - 0x37
     - 写 SN / F024
     - 手机 → 设备
     - ``06 00 37 00 10 …``
     - ≤16B SN
   * - 0x38
     - 写 SN 结果 / F024
     - 设备 → 手机
     - ``06 00 38 00 01 01``
     - 1B：``01`` 成功，``00`` 失败
   * - 0x39
     - 温度标定状态请求 / 单台温度、F028
     - 手机 → 设备
     - ``06 00 39 00 00``
     - Value 空
   * - 0x3A
     - 温度标定状态返回 / 单台温度、F028
     - 设备 → 手机
     - ``06 00 3A 00 05 …``
     - 1B 是否标定 + frequency 2B + initial 2B
   * - 0x3B
     - BF LE 广播 / LE 广播
     - 手机 → 设备
     - ``06 00 3B 00 00``
     - Value 空（HL：63BF LE 广播）
   * - 0x3C
     - BF DUT 模式 / DUT
     - 手机 → 设备
     - ``06 00 3C 00 00``
     - Value 空
   * - 0x3D
     - 默认功能读请求 / F049
     - 手机 → 设备
     - ``06 00 3D 00 00``
     - Value 空
   * - 0x3E
     - 默认功能读返回 / F049
     - 设备 → 手机
     - ``06 00 3E 00 01 …``
     - 1B 同 ``0x28`` 位定义
   * - 0x42
     - TP 检测开 / F014
     - 手机 → 设备
     - ``06 00 42 00 01 01``
     - 1B：``01`` 开，``00`` 关
   * - 0x43
     - TP 坐标 / F014
     - 设备 → 手机
     - ``06 00 43 00 04 …``
     - X 2B + Y 2B
   * - 0x44
     - License 读请求 / F025
     - 手机 → 设备
     - ``06 00 44 00 00``
     - Value 空
   * - 0x45
     - License 读返回 / F025
     - 设备 → 手机
     - ``06 00 45 00 3C …``
     - key 32B + UUID 16B + PID 8B 等（HL §6.45）
   * - 0x46
     - License 写 / F026、F030
     - 手机 → 设备
     - ``06 00 46 00 …``
     - 78B 组合 key/UUID/SN/MAC（HL §6.46）
   * - 0x47
     - License 写结果 / F026、F030
     - 设备 → 手机
     - ``06 00 47 00 01 01``
     - 1B：``01`` 成功
   * - 0x48
     - Opus 开 / F017
     - 手机 → 设备
     - ``06 00 48 00 01 01``
     - 1B：``01`` 开，``00`` 关
   * - 0x49
     - Opus 数据 / F017
     - 设备 → 手机
     - ``06 00 49 01 E0 …``
     - 480B 压缩块（可多帧）
   * - 0x4A
     - UV 检测开 / F015
     - 手机 → 设备
     - ``06 00 4A 00 01 01``
     - 1B 开关
   * - 0x4B
     - UV 等级 / F015
     - 设备 → 手机
     - ``06 00 4B 00 01 03``
     - 1B 等级 0～5
   * - 0x4C
     - PID 读请求 / F031、F051、F066
     - 手机 → 设备
     - ``06 00 4C 00 00``
     - Value 空
   * - 0x4D
     - PID 读返回 / F031、F051
     - 设备 → 手机
     - ``06 00 4D 00 08 …``
     - 8B PID 字符串
   * - 0x4E
     - PID 写 / F051
     - 手机 → 设备
     - ``06 00 4E 00 08 …``
     - 8B PID
   * - 0x4F
     - PID 写结果 / F051
     - 设备 → 手机
     - ``06 00 4F 00 01 01``
     - 1B：``01`` 成功
   * - 0x50
     - 固件产测结果请求 / 产测结果
     - 手机 → 设备
     - ``06 00 50 00 00``
     - Value 空
   * - 0x51
     - 固件产测结果 / 产测结果、老化
     - 设备 → 手机
     - ``06 00 51 00 1C …``
     - 28B：PCBA/半成品/成品汇总 + 分项 0 未过/1 过/2 不支持 + 是否老化
   * - 0x52
     - 烧录配置写 / F052、F043
     - 手机 → 设备
     - ``06 00 52 00 …``
     - 不定长 ASCII
   * - 0x53
     - 烧录配置读请求 / F052
     - 手机 → 设备
     - ``06 00 53 00 00``
     - Value 空
   * - 0x54
     - 烧录配置读返回 / F052
     - 设备 → 手机
     - ``06 00 54 00 …``
     - 不定长 ASCII
   * - 0x55
     - DVT 项数请求 / F021
     - 手机 → 设备
     - ``06 00 55 00 00``
     - Value 空
   * - 0x56
     - DVT 项数返回 / F021
     - 设备 → 手机
     - ``06 00 56 00 01 0B``
     - 1B 总数
   * - 0x57
     - DVT 切换项 / F021
     - 手机 → 设备
     - ``06 00 57 00 01 00``
     - 1B 项索引（活动/睡眠/… 见 HL §6.57）
   * - 0x58
     - 资源 OTA 状态请求 / F057
     - 手机 → 设备
     - ``06 00 58 00 00``
     - Value 空
   * - 0x59
     - 资源 OTA 状态 / F057
     - 设备 → 手机
     - ``06 00 59 00 01 01``
     - 1B：``01`` 成功，``00`` 失败
   * - 0x5A
     - DebugShow 请求 / F045
     - 手机 → 设备
     - ``06 00 5A 00 00``
     - Value 空
   * - 0x5B
     - DebugShow 返回 / F045
     - 设备 → 手机
     - ``06 00 5B 00 …``
     - 1B 模式（ASCII/数值）+ 内容
   * - 0xF2
     - 热应激·喝水 / F016
     - 手机 → 设备
     - ``06 00 F2 00 00``
     - Value 空，触发提醒
   * - 0xF3
     - 热应激·休息 / F016
     - 手机 → 设备
     - ``06 00 F3 00 00``
     - Value 空
   * - 0xF4
     - 热应激·体调 / F016
     - 手机 → 设备
     - ``06 00 F4 00 00``
     - Value 空
   * - 0xF5
     - 进入老化 / 老化模式
     - 手机 → 设备
     - ``06 00 F5 00 00``
     - Value 空；幂等
   * - 0xF6
     - 老化状态 / 老化模式
     - 设备 → 手机
     - ``06 00 F6 00 01 01``
     - 1B：01 成功/已在老化；02～05 退出/低电/充电等（HL §6.F6）
   * - 0xF7
     - HISTORY 地址请求 / F035
     - 手机 → 设备
     - ``06 00 F7 00 00``
     - Value 空
   * - 0xF8
     - HISTORY 地址 / F035
     - 设备 → 手机
     - ``06 00 F8 00 28 …``
     - 5×8B 读写地址（计步/睡眠/心率/血压/多运动）
   * - 0xFA
     - 产测结束请求 / F061、F043
     - 手机 → 设备
     - ``06 00 FA 00 00``
     - Value 空；设备倒计时关机
   * - 0xFB
     - 产测结束返回 / F061
     - 设备 → 手机
     - ``06 00 FB 00 00``
     - Value 空；App 解绑/断开
   * - 0xFC
     - RESET / F027、F043
     - 手机 → 设备
     - ``06 00 FC 00 00``
     - Value 空；License 取消或收尾复位
   * - 0xFE
     - 关机 / 单台关机
     - 手机 → 设备
     - ``06 00 FE 00 00``
     - Value 空

.. _cmd-0a-section-2:

规则
----

* 打开、关闭都没有 L2 回应，只有 L1 ACK。打开后一直收不到 0x03，说明固件不支持或当前没有日志，SDK 不报错。
* 日志内容由固件原样输出（文本或固件自己的格式），SDK 不解析、不拆行，按收到的顺序把原始字节追加到文件，文件按"设备 + 打开时间"命名，路径交给 App。
* 一帧最多 499 字节，可以带多行；一行太长时固件可以拆到多帧，SDK 只管按顺序拼接。
* 断开连接后手表自动关闭日志，不保存"已打开"的状态；重连后要再发 0x01。
* 日志会占用蓝牙带宽、增加功耗，量产 App 不打开，只在 Demo 调试页和联调时用。打开期间其它命令照常收发。
* 关闭后手表不再发 0x03；关闭前已经在路上的帧，SDK 照常写进文件。崩溃栈见 0x08 Dump Stack（本命令仅实时日志）。

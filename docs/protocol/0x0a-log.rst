0x0A 日志命令
=============

.. container:: doc-status

   **讨论中**　只做实时日志，用于联调：App 打开后手表把日志实时发过来，SDK 存成文件。沿用新协议文档 旧版协议（原文档未随仓库提供） 3.11 的三个 key，结构不改，只补清楚细节。手表上保存的日志、崩溃信息本阶段不拉取；崩溃信息保留 08 Dump Stack 命令，见第 4 节。

.. _cmd-0a-section-1-1:

命令格式
--------

以下为 L2 层命令格式，不含 L1 帧头。

.. list-table::
   :header-rows: 1
   :widths: 18 10 18 54
   :class: protocol-table command-format columns-4

   * - 字段
     - 长度
     - 取值
     - 说明
   * - L2 Header
     - 2B
     - 0A 00
     - Command = 0x0A 日志命令，Version = 0，Reserve = 0
   * - Key
     - 1B
     - 见 :ref:`消息定义 <cmd-0a-section-1-2>`
     - 每种消息一个 key
   * - Length
     - 2B
     - Value 的字节数
     - 不含 L2 Header、Key、Length 本身
   * - Value
     - 可变
     - 见 :ref:`具体命令 <cmd-0a-section-1-4>`
     - 只有 0x03 带数据

.. list-table:: 示例：打开日志
   :header-rows: 1
   :widths: auto
   :class: packet-table

   * - L2 Header
     - Key
     - Length
   * - ``0A 00``
     - ``01``
     - ``00 00``

消息定义
--------

.. list-table::
   :header-rows: 1
   :widths: auto
   :class: protocol-table columns-5

   * - Key
     - 名称
     - 方向
     - Value
     - 说明
   * - 0x01
     - 打开日志
     - 手机 → 手表
     - 无
     - 没有 L2 回应
   * - 0x02
     - 关闭日志
     - 手机 → 手表
     - 无
     - 没有 L2 回应
   * - 0x03
     - 日志发送
     - 手表 → 手机
     - 日志内容 0～499 字节
     - 打开期间持续发
   * - 0x04～0xFF
     - 保留
     - —
     - —
     - —

.. _cmd-0a-section-1-3:

交互规则
--------

1. 打开、关闭都没有 L2 回应，只有 L1 ACK。打开后一直收不到 0x03，说明固件不支持或当前没有日志，SDK 不报错。
2. 日志内容由固件原样输出（文本或固件自己的格式），SDK 不解析、不拆行，按收到的顺序把原始字节追加到文件，文件按"设备 + 打开时间"命名，路径交给 App。
3. 一帧最多 499 字节，可以带多行；一行太长时固件可以拆到多帧，SDK 只管按顺序拼接。
4. 断开连接后手表自动关闭日志，不保存"已打开"的状态；重连后要再发 0x01。
5. 日志会占用蓝牙带宽、增加功耗，量产 App 不打开，只在 Demo 调试页和联调时用。打开期间其它命令照常收发。
6. 关闭后手表不再发 0x03；关闭前已经在路上的帧，SDK 照常写进文件。

.. _cmd-0a-section-1-4:

具体命令
--------

* "具体的命令"一列为完整的 L2 数据（十六进制，大端序），可直接对照抓包。
* 完整过程见"交互示例"工作表；需要固件确认的问题见"待确认"工作表。

.. list-table::
   :header-rows: 1
   :widths: auto
   :class: protocol-table columns-6

   * - Key
     - 名称
     - 场景
     - 方向
     - 具体的命令
     - 数据说明
   * - 0x01
     - 打开日志
     - 打开
     - 手机 → 手表
     - ``0A 00 01 00 00``
     - 无。手表开始通过 0x03 往外发日志。没有 L2 回应；固件不支持时收不到日志
   * - 0x02
     - 关闭日志
     - 关闭
     - 手机 → 手表
     - ``0A 00 02 00 00``
     - 无。手表停止发日志。没有 L2 回应
   * - 0x03
     - 日志发送
     - 一行
     - 手表 → 手机
     - ``0A 00 03 00 12 5B 49 5D 20 62 6C 65 3A 20 6C 6F 67 69 6E 20 6F 6B 0A``
     - 日志内容 0～499 字节，固件原样输出，SDK 不解析，按原始字节存文件。示例：[I] ble: login ok
   * - 0x03
     - 日志发送
     - 多行
     - 手表 → 手机
     - ``0A 00 03 00 22 5B 57 5D 20 68 72 3A 20 73 69 67 6E 61 6C 20 77 65 61 6B 0A 5B 49 5D 20 68 72 3A 20 72 65 74 72 79 0A``
     - 一帧可以带多行，行之间用换行（0A）分隔。示例：两行

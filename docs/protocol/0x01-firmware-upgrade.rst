0x01 固件升级命令
=================

命令格式
--------

.. list-table:: L2 命令格式
   :header-rows: 1
   :widths: 18 10 18 54
   :class: protocol-table command-format columns-4

   * - 字段
     - 长度
     - 取值
     - 说明
   * - Header
     - 2B
     - 01 00
     - ``01 00`` = Command 0x01，Version 0
   * - Key
     - 1B
     - 见规则
     - 每条消息一个 Key
   * - Length
     - 2B
     - Value 字节数
     - Big-Endian
   * - Value
     - 可变
     - 见具体命令
     - 请求为空，返回 2B

规则
----

.. table:: 消息定义

   ======== ====================
   Key      定义
   ======== ====================
   ``0x01`` 进入固件升级模式请求
   ``0x02`` 进入固件升级模式返回
   ======== ====================

具体命令
--------

0x01 — 进入固件升级模式请求
~~~~~~~~~~~~~~~~~~~~~~~~~~~

**方向**\ ：手机 → 设备 \| **Value**\ ：空（Length = 0）

0x02 — 进入固件升级模式返回
~~~~~~~~~~~~~~~~~~~~~~~~~~~

**方向**\ ：设备 → 手机 \| **Value（2 bytes）**\ ：

.. table:: OTA 返回字段

   =========== ====== ============================================
   字段        大小   说明
   =========== ====== ============================================
   Status code 1 byte ``0x00``\ =OTA 成功；\ ``0x01``\ =OTA 失败
   Error code  1 byte ``0x01``\ =电量过低（仅 status=0x01 时有效）
   =========== ====== ============================================

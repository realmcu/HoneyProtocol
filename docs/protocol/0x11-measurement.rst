0x11 点测命令
=============

.. container:: doc-status

   **第一版本**\ 　即时点测、运动过程与心电预留；历史/今日见 :doc:`数据命令 <0x05-data>`。

.. _cmd-11-section-1:

命令格式
--------

.. list-table:: L2 命令格式
   :header-rows: 1
   :widths: 18 10 18 54
   :class: protocol-table command-format columns-4

   * - 字段
     - 长度
     - 取值
     - 说明
   * - Header
     - 2B
     - 11 00
     - ``11 00`` = Command 0x11，Version 0
   * - Key
     - 1B
     - —
     - 见 :ref:`规则 <cmd-11-section-2>`
   * - Length
     - 2B
     - —
     - Value 字节数（大端）
   * - Value
     - 可变
     - —
     - 见 :ref:`具体命令 <cmd-11-section-3>`

* 大端；时间 4B 墙上时钟秒（同 0x05）。**无**\ 进度、预计时长、记录版本字节。
* **类型码**\ （0x05 同步/状态）与 **点测 Key**\ （本命令 1B Key）两套编号；仅心率类型码 ``0x03`` 与开始 Key ``0x03`` 相同。
* 历史/今日见 :doc:`数据命令 <0x05-data>`；运动摘要见 0x05 ``0x2A``\ ，详情 ``0x80``/``0x81``\ 。

.. _cmd-11-section-2:

规则
----

.. list-table:: Key 分组
   :header-rows: 1
   :widths: auto
   :class: protocol-table columns-2 key-interaction

   * - 号段
     - 用途
   * - ``0x01``\ ～``0x02``
     - 全局点测忙闲查询/状态（7B）
   * - ``0x03``\ ～``0x2A``
     - 健康点测五连（开始→回应→停止→实时→结果）；``0x2B``\ ～``0x5F`` 预留
   * - ``0x60``\ ～``0x6A``
     - 运动过程（与实时心率 ``0x26`` 块分开）
   * - ``0x6B``\ ～``0x70``
     - 心电（暂不做）

* 同时仅一项点测/运动控制；其它「开始」回应 ``01`` 忙。开始回应 **仅 1B 结果**\ （``00``/``01``\ ），无预计时长。
* 运动：**``0x63``** 约 1Hz 整帧 23B（非 0x05 详情流式）；**``0x67``/``0x68``** 查未结束场次；**``0x69``/``0x6A``** 订阅/停推 ``0x63``\ （不停表）；结束 **``0x64``**\ （可带 31B 摘要）。
* 点测成功结果 = **结果 1B + 记录**\ （布局同 0x05 各类型）；失败通常仅结果 1B。结果码：``00`` 成功/已开始，``01`` 忙或手机停止，``02+`` 扩展失败。
* 具体命令按 Key 排序；「具体的命令」为完整 L2 hex。示例时刻 2026-10-12 08:30:00 = ``6A CC 9A 88``\ 。

.. _cmd-11-section-3:

具体命令
--------

.. list-table:: 协议数据示例
   :header-rows: 1
   :widths: 5 20 10 15 50
   :class: protocol-table command-detail columns-5

   * - Key
     - 名称 / 用途
     - 方向
     - 具体的命令
     - 数据说明
   * - 0x01
     - 查询状态 / 当前进行项
     - 手机 → 手表
     - ``11 00 01 00 00``
     - Value **空**\ 。询问当前是否有点测类任务占用（不含「未结束运动场次」，那场用 Key ``0x67`` 查）。
   * - 0x02
     - 状态 / 进行中
     - 手表 → 手机
     - ``11 00 02 00 07 01 03 00 6A CC 9A 88``
     - Value **7B**\ ：**状态** 1B（``00`` 空闲，``01`` 有点测进行中）+ **类型** 1B（数据类型码，如 ``03`` 心率；空闲填 ``00``\ ）+ **发起方** 1B（``00`` 手机发起，``01`` 手表发起）+ **开始时间** 4B（墙上时钟秒；空闲时填 0）。示例：进行中、心率点测、手机发起、2026-10-12 08:30:00。
   * - 0x02
     - 状态 / 空闲
     - 手表 → 手机
     - ``11 00 02 00 07 00 00 00 00 00 00 00``
     - Value 同上；**空闲**\ 示例：状态=00，其余填 0。
   * - 0x03
     - 心率·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 03 00 00``
     - Value **空**\ 。请求开始单次心率测量；手表若空闲则进入测量并先发 Key ``0x04`` 开始回应。
   * - 0x04
     - 心率·开始回应 / 已开始
     - 手表 → 手机
     - ``11 00 04 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始（随后约 1Hz 推 Key ``0x06`` 实时）；``01`` 忙，不推实时。
   * - 0x04
     - 心率·开始回应 / 设备忙
     - 手表 → 手机
     - ``11 00 04 00 01 01``
     - Value **1B 结果**\ ：``01`` 设备忙。
   * - 0x05
     - 心率·停止 / 手机停止
     - 手机 → 手表
     - ``11 00 05 00 00``
     - Value **空**\ 。请求中止测量；手表停止推实时并发 Key ``0x07``\ ，结果码一般为 ``01``\ （手机停止），通常**不带**\ 成功记录。
   * - 0x06
     - 心率·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 06 00 01 48``
     - Value **1B**\ ：当前心率 bpm；无效 ``FF``\ 。测量过程中约每秒一条。
   * - 0x07
     - 心率·结果 / 测量结果
     - 手表 → 手机
     - ``11 00 07 00 06 00 6A CC 9A A6 48``
     - Value：**结果 1B** + **记录 5B**\ （成功时）。记录 = 时间戳 4B + 心率 1B（与 0x05 类型 0x03 相同）。示例：结果 ``00`` 成功，时刻 2026-10-12 08:30:46，72 bpm。
   * - 0x08
     - 血压·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 08 00 00``
     - Value **空**\ 。开始单次血压测量。
   * - 0x09
     - 血压·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 09 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始；``01`` 忙。
   * - 0x0A
     - 血压·停止 / 手机停止
     - 手机 → 手表
     - ``11 00 0A 00 00``
     - Value **空**\ 。中止测量；手表发 Key ``0x0C`` 结果，结果码 ``01`` 手机停止。
   * - 0x0B
     - 血压·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 0B 00 01 4B``
     - Value **1B**\ ：测量过程中的参考心率 bpm（非血压值）；无效 ``FF``\ 。
   * - 0x0C
     - 血压·结果 / 测量结果
     - 手表 → 手机
     - ``11 00 0C 00 07 00 6A CC 9A C4 78 50``
     - Value：**结果 1B** + **记录 6B**\ （成功时）。记录 = 时间戳 4B + 收缩压 1B + 舒张压 1B（类型 0x04）。示例：成功，120/80 mmHg。
   * - 0x0D
     - 血氧·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 0D 00 00``
     - Value **空**\ 。开始单次血氧测量。
   * - 0x0E
     - 血氧·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 0E 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始；``01`` 忙。
   * - 0x0F
     - 血氧·停止 / 手机停止
     - 手机 → 手表
     - ``11 00 0F 00 00``
     - Value **空**\ 。中止测量；手表发 Key ``0x11`` 结果。
   * - 0x10
     - 血氧·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 10 00 01 62``
     - Value **1B**\ ：当前血氧 %；无效 ``FF``\ 。
   * - 0x11
     - 血氧·结果 / 测量结果
     - 手表 → 手机
     - ``11 00 11 00 08 00 6A CC 9A C4 62 63 60``
     - Value：**结果 1B** + **记录 7B**\ （成功时）。记录 = 时间戳 4B + 当前 % 1B + 最高 % 1B + 最低 % 1B（类型 0x05，无则 ``FF``\ ）。示例：成功，98%，高 99%、低 96%。
   * - 0x12
     - HRV·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 12 00 00``
     - Value **空**\ 。开始单次 HRV 测量。
   * - 0x13
     - HRV·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 13 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始；``01`` 忙。
   * - 0x14
     - HRV·停止 / 手机停止
     - 手机 → 手表
     - ``11 00 14 00 00``
     - Value **空**\ 。中止测量；手表发 Key ``0x16`` 结果。
   * - 0x15
     - HRV·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 15 00 02 00 2D``
     - Value **2B**\ ：当前 SDNN（ms，大端）；无效 ``FFFF``\ 。
   * - 0x16
     - HRV·结果 / 测量结果
     - 手表 → 手机
     - ``11 00 16 00 07 00 6A CC 9A C4 00 34``
     - Value：**结果 1B** + **记录 6B**\ （成功时）。记录 = 时间戳 4B + SDNN ms 2B（类型 0x06）。示例：成功，52 ms。
   * - 0x17
     - 压力·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 17 00 00``
     - Value **空**\ 。开始单次压力测量。
   * - 0x18
     - 压力·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 18 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始；``01`` 忙。
   * - 0x19
     - 压力·停止 / 手机停止
     - 手机 → 手表
     - ``11 00 19 00 00``
     - Value **空**\ 。中止测量；手表发 Key ``0x1B`` 结果。
   * - 0x1A
     - 压力·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 1A 00 01 23``
     - Value **1B**\ ：当前压力值（1～99）；无效 ``FF``\ 。
   * - 0x1B
     - 压力·结果 / 测量结果
     - 手表 → 手机
     - ``11 00 1B 00 06 00 6A CC 9A C4 3E``
     - Value：**结果 1B** + **记录 5B**\ （成功时）。记录 = 时间戳 4B + 压力 1B（类型 0x07）。示例：成功，62。
   * - 0x1C
     - 体温·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 1C 00 00``
     - Value **空**\ 。开始单次体温测量。
   * - 0x1D
     - 体温·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 1D 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始；``01`` 忙。
   * - 0x1E
     - 体温·停止 / 手机停止
     - 手机 → 手表
     - ``11 00 1E 00 00``
     - Value **空**\ 。中止测量；手表发 Key ``0x20`` 结果。
   * - 0x1F
     - 体温·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 1F 00 02 0E 44``
     - Value **2B**\ ：当前体温 0.01 ℃（大端）；未佩戴 ``8000``\ 。
   * - 0x20
     - 体温·结果 / 测量结果
     - 手表 → 手机
     - ``11 00 20 00 0B 00 6A CC 9A C4 0E 44 0C EE 00 03``
     - Value：**结果 1B** + **记录 10B**\ （成功时）。记录布局同 0x05 类型 0x08（体温/皮肤温/热应激/标志）。示例：成功，36.68 ℃。
   * - 0x21
     - 血糖·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 21 00 00``
     - Value **空**\ 。开始单次血糖测量。
   * - 0x22
     - 血糖·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 22 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始；``01`` 忙。
   * - 0x23
     - 血糖·停止 / 手机停止
     - 手机 → 手表
     - ``11 00 23 00 00``
     - Value **空**\ 。中止测量；手表发 Key ``0x25`` 结果。
   * - 0x24
     - 血糖·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 24 00 02 00 48``
     - Value **2B**\ ：当前血糖 0.1 mmol/L（大端）。
   * - 0x25
     - 血糖·结果 / 测量结果
     - 手表 → 手机
     - ``11 00 25 00 07 00 6A CC 9A C4 00 48``
     - Value：**结果 1B** + **记录 6B**\ （成功时）。记录 = 时间戳 4B + 血糖 0.1 mmol/L 2B（类型 0x09）。示例：成功，7.2 mmol/L。
   * - 0x26
     - 实时心率·开始 / 持续监测
     - 手机 → 手表
     - ``11 00 26 00 00``
     - Value **空**\ 。进入持续心率监测（非单次点测）；不与运动 Key ``0x60`` 块混用。
   * - 0x27
     - 实时心率·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 27 00 01 00``
     - Value **1B 结果**\ ：``00`` 已开始；``01`` 忙。
   * - 0x28
     - 实时心率·停止 / 结束监测
     - 手机 → 手表
     - ``11 00 28 00 00``
     - Value **空**\ 。结束持续监测。
   * - 0x29
     - 实时心率·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 29 00 01 76``
     - Value **1B**\ ：当前心率 bpm。
   * - 0x2A
     - 实时心率·结果 / 结束结果
     - 手表 → 手机
     - ``11 00 2A 00 01 00``
     - Value **仅结果 1B**\ （如 ``00`` 正常结束）；**不带**\ 历史记录。
   * - 0x60
     - 运动·开始 / 发起运动
     - 手机 → 手表
     - ``11 00 60 00 01 01``
     - Value **1B 运动模式**\ （如 ``01`` 户外跑步，与 0x05 摘要模式编号一致）。
   * - 0x61
     - 运动·开始回应 / 开始结果
     - 手表 → 手机
     - ``11 00 61 00 02 01 00``
     - Value **2B**\ ：**模式** 1B（回显）+ **结果** 1B（``00`` 已开始）。成功后手机发起场景固件**默认**\ 约 1Hz 推 Key ``0x63``\ （等同已订阅）。
   * - 0x62
     - 运动·控制 / 结束
     - 手机 → 手表
     - ``11 00 62 00 01 00``
     - Value **1B 动作**\ ：``00`` 结束本场（手表随后发 Key ``0x64``\ ）；``01`` 暂停；``02`` 继续。
   * - 0x62
     - 运动·控制 / 暂停
     - 手机 → 手表
     - ``11 00 62 00 01 01``
     - Value **1B 动作**\ ：``01`` 暂停；下一条 Key ``0x63`` 里状态字节为 ``02``\ 。
   * - 0x63
     - 运动·实时 / 过程数据
     - 手表 → 手机
     - ``11 00 63 00 17 01 01 6A CC 9A 88 …``
     - Value **定长 23B**\ （整帧，非流式）：模式 1B + 状态 1B（``01`` 运动中 ``02`` 已暂停）+ 开始时间 4B + 运动时长 4B（秒，不含暂停）+ 心率 1B + 步数 4B + 距离 4B + 卡路里 4B（0.1 kcal）。约 1Hz，在订阅生效或手机发起开始后推送。
   * - 0x64
     - 运动·结束 / 场次结果
     - 手表 → 手机
     - ``11 00 64 …``
     - Value：**结果 1B** + **结束方 1B**\ （``00`` 手机结束 ``01`` 手表结束）+ **摘要 31B**\ （可选，与 :doc:`数据命令 <0x05-data>` 的 ``0x2A`` 相同，含 sport_id、detail_flags 等）。结果 ``00`` 表示场次已保存。与是否订阅 Key ``0x69`` 无关，结束都应通知手机。
   * - 0x65
     - 查询运动模式 / 支持列表
     - 手机 → 手表
     - ``11 00 65 00 00``
     - Value **空**\ 。请求本机支持的运动模式编号列表。
   * - 0x66
     - 运动模式列表 / 查询回应
     - 手表 → 手机
     - ``11 00 66 00 04 03 01 02 03``
     - Value：**个数 N** 1B + **模式** 1B × N（每个为支持的模式编号，如 01/02/03）。示例：3 种模式。
   * - 0x67
     - 查询运动状态 / 未结束场次
     - 手机 → 手表
     - ``11 00 67 00 00``
     - Value **空**\ 。查询是否存在**未结束**\ 的运动场次（与 Key ``0x01`` 全局点测忙闲分开）。
   * - 0x68
     - 运动状态 / 无未结束场次
     - 手表 → 手机
     - ``11 00 68 00 01 00``
     - Value **1B 结果**\ ：``00`` **没有**\ 未结束运动（仅此 1 字节）。
   * - 0x68
     - 运动状态 / 有未结束场次
     - 手表 → 手机
     - ``11 00 68 00 18 01 …``
     - Value：**结果 1B** ``01`` **有**\ 未结束运动 + **23B 快照**\ （字段与 Key ``0x63`` 完全相同，便于 App 用开始时间+模式对本地缓存）。
   * - 0x69
     - 开始订阅实时 / 订阅过程数据
     - 手机 → 手表
     - ``11 00 69 00 00``
     - Value **空**\ 。**无订阅回应 Key**\ ；接受后手表按约 1Hz 推 Key ``0x63``\ 。无未结束运动时可不推。
   * - 0x6A
     - 结束订阅实时 / 停止过程数据
     - 手机 → 手表
     - ``11 00 6A 00 00``
     - Value **空**\ 。**无回应**\ ；手表停止推 Key ``0x63``\ ，**不结束**\ 运动计时。
   * - 0x6B
     - 心电·开始 / 发起测量
     - 手机 → 手表
     - ``11 00 6B 00 00``
     - Value **空**\ 。协议预留，当前版本不实现。
   * - 0x6C
     - 心电·开始回应 / 开始结果
     - 手表 → 手机
     - —
     - Value：**结果 1B** + 采样率 2B + 幅值单位 2B（结果非 ``00`` 时后 4B 填 0）。
   * - 0x6D
     - 心电·停止 / 手机停止
     - 手机 → 手表
     - —
     - Value **空**\ 。
   * - 0x6E
     - 心电·波形 / 过程数据
     - 手表 → 手机
     - —
     - Value：波形数据块（流式，细节待定）。
   * - 0x6F
     - 心电·实时参数 / 过程数据
     - 手表 → 手机
     - —
     - Value **2B**\ ：导联状态 1B + 心率 1B。
   * - 0x70
     - 心电·结果 / 测量结果
     - 手表 → 手机
     - —
     - Value：**结果 1B**\ ；成功时 + **记录 14B**\ （无版本字节）。

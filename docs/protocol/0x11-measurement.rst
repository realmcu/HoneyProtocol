0x11 点测命令
=============

.. container:: doc-status

   **讨论中**　本文讲即时测量，按 key 分三组：单项测量（含实时心率）、运动、心电。运动、心电是特殊的数据，各自用一组独立的 key；三组共用查询状态，同一时间只能有一项。历史数据和今日数据在数据命令 0x05，见 :doc:`数据命令 <0x05-data>`。运动的实时数据字段还没定、心电暂不做，先按草案写，见第 9 节。

.. _cmd-11-section-1-1:

命令格式
--------

以下为 L2 层命令格式，不含 L1 帧头。

.. list-table::
   :header-rows: 1
   :widths: 18 10 18 54
   :class: protocol-table command-format columns-4

   * - 字段
     - 长度
     - 取值
     - 说明
   * - L2 Header
     - 2B
     - 11 00
     - Command = 0x11 点测命令，Version = 0，Reserve = 0
   * - Key
     - 1B
     - 见 :ref:`消息定义 <cmd-11-section-1-3>`
     - 每种消息一个 key
   * - Length
     - 2B
     - Value 的字节数
     - 不含 L2 Header、Key、Length 本身
   * - Value
     - 可变
     - 见 :ref:`具体命令 <cmd-11-section-1-5>`
     - 每种消息各自定义

.. list-table:: 示例：手机发起一次心率测量
   :header-rows: 1
   :widths: auto
   :class: packet-table

   * - L2 Header
     - Key
     - Length
     - Value
   * - ``11 00``
     - ``01``
     - ``00 01``
     - ``03``

Value = 03 心率

* 多字节整数一律大端序，时间一律用 4B 时间戳（1970 年起的墙上时钟秒），和数据命令 0x05 相同。
* 命令号 0x11：0x01～0x10 已被其它命令占用或预留（0x0E 视频流、0x0F 远程控制只有宏定义），0x0B 是文件传输原来的编号，不用。

.. _cmd-11-section-1-2:

Key 分组
--------

.. list-table::
   :header-rows: 1
   :widths: auto
   :class: protocol-table columns-3

   * - Key 范围
     - 分组
     - 说明
   * - 0x01～0x0F
     - 单项测量
     - 心率、血压、血氧、HRV、压力、体温、血糖、实时心率；查询状态 0x04 / 0x05 三组共用
   * - 0x10～0x1F
     - 运动
     - 开始、暂停、继续、结束，运动中的实时数据，结束时的运动记录
   * - 0x20～0x2F
     - 心电
     - 开始、停止，测量中的波形和实时参数，结果。暂不做
   * - 0x30～0xFF
     - 保留
     - 以后新增分组

* 运动、心电和单项测量的交互差别大（运动要暂停继续、断开后继续跑；心电要连续发波形），所以各自一组 key，Value 各自定义，不和单项测量共用开始、停止、结果。
* 组内新增 key 接在后面，不插入、不重排。

消息定义
--------

.. list-table::
   :header-rows: 1
   :widths: auto
   :class: protocol-table columns-5

   * - Key
     - 名称
     - 方向
     - Value
     - 说明
   * - 0x01
     - 开始
     - 手机 → 手表
     - 类型 1B
     - 单项测量、实时心率，不带参数。手表回 0x02
   * - 0x02
     - 开始回应
     - 手表 → 手机
     - 类型 1B + 结果 1B + 预计时长 2B
     - 结果：00 已开始，01 忙，02 未佩戴，03 不支持，04 电量低，05 充电中，06 参数错误。预计时长单位秒，实时心率填 0（不定）
   * - 0x03
     - 停止
     - 手机 → 手表
     - 类型 1B
     - 手表不单独回应，停止后发 0x07（01 手机停止）；没有在进行这项时忽略
   * - 0x04
     - 查询状态
     - 手机 → 手表
     - 无
     - 三组共用。手表回 0x05
   * - 0x05
     - 状态
     - 手表 → 手机
     - 状态 1B + 类型 1B + 发起方 1B + 开始时间 4B
     - 三组共用，见 :ref:`状态和互斥（三组共用） <cmd-11-section-1-4>`
   * - 0x06
     - 实时数据
     - 手表 → 手机
     - 类型 1B + 版本 1B + 数据
     - 测量中约每秒一条，见 2.4
   * - 0x07
     - 结果
     - 手表 → 手机
     - 类型 1B + 结果 1B + 记录版本 1B + 记录
     - 结果：00 成功，01 手机停止，02 手表上停止，03 未佩戴，04 信号差，05 超时，06 被打断。成功时带记录，格式和 0x05 同一类型的记录相同；不成功只有类型 + 结果
   * - 0x08～0x0F
     - 保留
     - —
     - —
     - —
   * - 0x10
     - 运动开始
     - 手机 → 手表
     - 运动模式 1B
     - 手表回 0x11
   * - 0x11
     - 运动开始回应
     - 手表 → 手机
     - 运动模式 1B + 结果 1B
     - 结果：00 已开始，01 忙，02 不支持这个运动模式，03 电量低，04 充电中
   * - 0x12
     - 运动控制
     - 手机 → 手表
     - 动作 1B
     - 动作：00 结束，01 暂停，02 继续。手表不单独回应：暂停、继续看 0x13 里的状态，结束看 0x14。已经是目标状态（暂停中再暂停）、没有在进行的运动，手表忽略
   * - 0x13
     - 运动实时数据
     - 手表 → 手机
     - 版本 1B + 数据
     - 运动中、暂停中每秒一条，见 3.2（草案）
   * - 0x14
     - 运动结束
     - 手表 → 手机
     - 结果 1B + 结束方 1B + 记录版本 1B + 运动记录
     - 结果：00 已保存，01 时间太短未保存；结束方：00 手机，01 手表上结束，02 手表自动结束（低电等）。已保存时带运动记录，格式和 0x05 类型 0x0A 相同（待定义）；未保存只有结果 + 结束方
   * - 0x15
     - 查询运动模式
     - 手机 → 手表
     - 无
     - 手表回 0x16
   * - 0x16
     - 运动模式列表
     - 手表 → 手机
     - 个数 1B + 运动模式 1B × 个数
     - 手表支持的运动模式，App 只显示这些
   * - 0x17～0x1F
     - 保留
     - —
     - —
     - —
   * - 0x20
     - 心电开始
     - 手机 → 手表
     - 无
     - 手表回 0x21
   * - 0x21
     - 心电开始回应
     - 手表 → 手机
     - 结果 1B + 预计时长 2B + 采样率 2B + 幅值单位 2B
     - 结果：00 已开始，01 忙，02 未佩戴，03 不支持，04 电量低，05 充电中。预计时长单位秒；采样率单位 Hz；幅值单位 = 每个采样值代表多少 nV。结果不是 00 时后面填 0
   * - 0x22
     - 心电停止
     - 手机 → 手表
     - 无
     - 手表不单独回应，停止后发 0x25（01 手机停止）；没有在测时忽略
   * - 0x23
     - 心电波形
     - 手表 → 手机
     - 序号 2B + 点数 1B + 采样值 2B × 点数
     - 测量中连续发，见 4.2
   * - 0x24
     - 心电实时参数
     - 手表 → 手机
     - 版本 1B + 进度 1B + 导联 1B + 心率 1B
     - 测量中每秒一条，见 4.3
   * - 0x25
     - 心电结果
     - 手表 → 手机
     - 结果 1B + 记录版本 1B + 记录
     - 结果：00 成功，01 手机停止，02 手表上停止，03 导联脱落，04 信号差，05 超时，06 被打断。成功时带心电记录（见 4.4）；不成功只有结果
   * - 0x26～0x2F
     - 保留
     - —
     - —
     - —

.. _cmd-11-section-1-4:

状态和互斥（三组共用）
----------------------

1. 一次只做一项：单项测量、实时心率、运动、心电同一时间只能有一项，包括用户在手表上发起的。正在进行时，各组的开始都回 01 忙；App 可以发 0x04 查是什么在进行，想换要先停止。
2. 状态 0x05：状态 1B（00 空闲，01 进行中，02 已暂停，只有运动有）+ 类型 1B（共用类型表：0x03～0x09 单项测量，0x0A 运动，0x0C 心电，0x0D 实时心率）+ 发起方 1B（00 手机，01 手表）+ 开始时间 4B。空闲时后面 6 字节填 FF。
3. 手表只在回 0x04 时发 0x05，不主动发；开始、结束看各组的开始回应和结果，运动的暂停、继续看 0x13 里的状态。
4. 手表上发起的：手表不发实时数据、结果给 App，查询状态能看到（发起方 = 01 手表）。要不要通知 App 待讨论，见第 9 节。
5. 回应超时：手机发出请求后 5 秒没收到对应的回应，视为失败。停止（0x03）、运动控制（0x12）、心电停止（0x22）都没有单独的回应：5 秒内没看到状态变化或结果，App 发 0x04 查询状态确认。
6. 断开：单项测量手表继续测完；实时心率、心电手表自动停止；运动手表上继续。重连登录后 App 发 0x04 查询，手机发起的运动还在进行，手表回 0x05 后接着恢复发 0x13。
7. 自动监测：测量、运动进行中，手表自己决定暂停哪些自动监测，结束后恢复，App 不用管。
8. 和数据命令 0x05 互不影响：点测进行中，历史同步、今日数据照常进行。测心电时数据量大，SDK 最好先不拉历史。
9. 类型码和数据命令 0x05 共用一张表，结果记录的格式也相同，SDK 共用解析。
10. 扩展：实时数据、实时参数带格式版本，结果带记录版本，规则同 0x05 的 1.8：末尾加字段不升版本，不兼容的改动升版本，老 SDK 不认识的版本不解析。

具体命令
--------

* "具体的命令"一列为完整的 L2 数据（十六进制，大端序），可直接对照抓包。
* 示例的时间戳都在 2026-10-12：08:30:00 = 6A CC 9A 88。
* 三组的说明和数据格式见"单项测量""运动""心电"工作表；所有命令的具体示例见本表:ref:`具体命令 <cmd-11-section-1-5>`；完整过程见"交互示例"工作表；需要固件确认和待讨论的问题见"待确认"工作表。

   :header-rows: 1
   :widths: auto
   :class: protocol-table columns-6

   * - Key
     - 名称
     - 场景
     - 方向
     - 具体的命令
     - 数据说明
   * - 0x01
     - 开始
     - 测心率
     - 手机 → 手表
     - ``11 00 01 00 01 03``
     - 类型 1B，不带参数。手表回 0x02。示例：03 心率
   * - 0x01
     - 开始
     - 测血压
     - 手机 → 手表
     - ``11 00 01 00 01 04``
     - 示例：04 血压
   * - 0x01
     - 开始
     - 实时心率
     - 手机 → 手表
     - ``11 00 01 00 01 0D``
     - 示例：0D 实时心率，手表只当心率带用
   * - 0x02
     - 开始回应
     - 已开始
     - 手表 → 手机
     - ``11 00 02 00 04 03 00 00 1E``
     - 类型 1B + 结果 1B（00 已开始，01 忙，02 未佩戴，03 不支持，04 电量低，05 充电中，06 参数错误）+ 预计时长 2B（秒；实时心率填 0 表示不定；结果不是 00 时填 0）。示例：03 心率；00 已开始；00 1E 预计 30 秒
   * - 0x02
     - 开始回应
     - 实时心率已开始
     - 手表 → 手机
     - ``11 00 02 00 04 0D 00 00 00``
     - 示例：0D 实时心率；00 已开始；00 00 不定
   * - 0x02
     - 开始回应
     - 忙
     - 手表 → 手机
     - ``11 00 02 00 04 04 01 00 00``
     - 示例：04 血压；01 忙，已有测量、实时心率、运动或心电在进行（包括手表上发起的），App 可以发 0x04 查是什么
   * - 0x02
     - 开始回应
     - 未佩戴
     - 手表 → 手机
     - ``11 00 02 00 04 05 02 00 00``
     - 示例：05 血氧；02 未佩戴
   * - 0x02
     - 开始回应
     - 不支持
     - 手表 → 手机
     - ``11 00 02 00 04 09 03 00 00``
     - 示例：09 血糖；03 这个手表不支持
   * - 0x03
     - 停止
     - 停止测量
     - 手机 → 手表
     - ``11 00 03 00 01 03``
     - 类型 1B。手表不单独回应，停止后发 0x07（01 手机停止）；没有在进行这项时忽略。示例：03 心率
   * - 0x03
     - 停止
     - 停止实时心率
     - 手机 → 手表
     - ``11 00 03 00 01 0D``
     - 示例：0D 实时心率
   * - 0x04
     - 查询状态
     - 查询
     - 手机 → 手表
     - ``11 00 04 00 00``
     - 无 Value，三组共用。手表回 0x05。重连登录后发一次
   * - 0x05
     - 状态
     - 空闲
     - 手表 → 手机
     - ``11 00 05 00 07 00 FF FF FF FF FF FF``
     - 状态 1B（00 空闲，01 进行中，02 已暂停）+ 类型 1B + 发起方 1B（00 手机，01 手表）+ 开始时间 4B；空闲时后面 6 字节填 FF。三组共用，手表只在回 0x04 时发。示例：00 空闲
   * - 0x05
     - 状态
     - 手机发起的心率
     - 手表 → 手机
     - ``11 00 05 00 07 01 03 00 6A CC 9A 88``
     - 示例：01 进行中；03 心率；00 手机发起；6A CC 9A 88 08:30 开始
   * - 0x05
     - 状态
     - 手表上发起的血压
     - 手表 → 手机

   * - 0x05
     - 状态
     - 手机发起的运动

   * - 0x05
     - 状态
     - 运动已暂停
     - 手表 → 手机
     - ``11 00 05 00 07 02 0A 00 6A CC 9A 88``
     - 示例：02 已暂停；0A 运动；00 手机发起
   * - 0x05
     - 状态
     - 手表上发起的运动
     - 手表 → 手机
     - ``11 00 05 00 07 01 0A 01 6A CC 85 70``
     - 示例：01 进行中；0A 运动；01 手表上发起；6A CC 85 70 07:00 开始。App 不收实时数据，也不能控制
   * - 0x05
     - 状态
     - 心电中
     - 手表 → 手机

   * - 0x06
     - 实时数据
     - 心率
     - 手表 → 手机
     - ``11 00 06 00 04 03 01 32 48``
     - 类型 1B + 版本 1B + 数据（按类型定，见 2.4）。测量中约每秒一条，只发手机发起的。示例：03 心率；01 版本 1；32 进度 50%；48 72 bpm
   * - 0x06
     - 实时数据
     - 心率还没出值
     - 手表 → 手机
     - ``11 00 06 00 04 03 01 0A FF``

   * - 0x06
     - 实时数据
     - 血压
     - 手表 → 手机
     - ``11 00 06 00 04 04 01 28 4B``

   * - 0x06
     - 实时数据
     - 血氧
     - 手表 → 手机
     - ``11 00 06 00 04 05 01 50 62``

   * - 0x06
     - 实时数据
     - 体温
     - 手表 → 手机
     - ``11 00 06 00 05 08 01 3C 0E 44``
     - 示例：08 体温；3C 进度 60%；0E 44 体温 36.52 ℃
   * - 0x06
     - 实时数据
     - 实时心率
     - 手表 → 手机
     - ``11 00 06 00 03 0D 01 48``
     - 示例：0D 实时心率；01 版本 1；48 72 bpm（没戴好、还没出值填 FF）
   * - 0x07

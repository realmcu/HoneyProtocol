# 3 L2 Command 详解

## 3.1 Command 列表

**实现状态**一列反映设备端固件当前实况：**已实现**=有完整业务逻辑； **桩**=handler 已注册但仅打印日志，收到指令不做任何处理、不回响应（L1 层仍会 ACK，手机端若等待 L2 响应会超时）；**未实现**=未注册 handler。

| Command ID | 命令                                            | 实现状态                                                 |
|------------|-------------------------------------------------|----------------------------------------------------------|
| `0x01`     | [固件升级命令](0x01-firmware-upgrade.md)                                    | 桩                                                       |
| `0x02`     | [设置命令](0x02-settings.md)                                        | 已实现（仅 `0x01` 时间设置）                             |
| `0x03`     | [绑定命令](0x03-bind.md)                                        | 已实现（`0x01`/`0x05`）                                  |
| `0x04`     | [提醒命令](0x04-reminder.md)                                        | 桩                                                       |
| `0x05`     | [运动数据命令](0x05-sport-data.md)                                    | 已实现（运动 `0x01`；睡眠 `0x02` 待补存储层，详见 [§3.6](0x05-sport-data.md)） |
| `0x06`     | [工厂测试命令](0x06-factory-test.md)                                    | 桩                                                       |
| `0x07`     | [控制命令](0x07-control.md)                                        | 桩                                                       |
| `0x08`     | [Dump Stack 命令](0x08-dump-stack.md)                                 | 未实现                                                   |
| `0x09`     | [测试 Flash 读取命令](0x09-flash-read.md)                             | 未实现                                                   |
| `0x0a`     | [日志命令](0x0a-log.md)                                        | 桩                                                       |
| `0x10`     | [文件传输命令](0x10-file-transfer.md)（**注意**：原定 `0x0b`，见 [§3.12](0x10-file-transfer.md)） | 已实现                                                   |
| `0x0c`     | [BLE 连接参数命令](0x0c-ble-conn-param.md)                                | 已实现                                                   |
| `0x0d`     | [WiFi 配网命令](0x0d-wifi-provision.md)                                   | 未实现                                                   |

!!! note "说明"

    设备端头文件 `hmi_l2.h` 另外预留了两个本文档未定义的命令： `0x0e`（视频流 STREAM）与 `0x0f`（远程控制 REMOTE）。两者目前只有宏定义，无 handler 实现，规范待补。

3.8 控制命令 (command id 0x07)
==============================

.. warning:: 规范版本

   Excel 新协议已将旧 ``0x07`` 控制交互合并到通知命令 ``0x04``，``0x07`` 编号保留不用。本页仅记录旧实现。

L2 版本号：\ **0**

======== ================ ========= ==================================
Key      定义             方向      Value
======== ================ ========= ==================================
``0x01`` 拍照控制         设备→手机 空
``0x02`` 单击控制         设备→手机 空
``0x03`` 双击控制         设备→手机 空
``0x11`` 相机应用状态请求 手机→设备 ``0x00``\ =前台；\ ``0x01``\ =后台
======== ================ ========= ==================================

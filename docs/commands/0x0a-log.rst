3.11 日志命令 (command id 0x0a)
===============================

.. note:: 规范版本

   Excel 新规范见 `0x0A 日志命令 <../protocol/0x0a-log.html>`__。

L2 版本号：\ **0**

======== ============ ========= ======================
Key      定义         方向      Value
======== ============ ========= ======================
``0x01`` 打开日志功能 手机→设备 空
``0x02`` 关闭日志功能 手机→设备 空
``0x03`` 日志发送     设备→手机 0~499 bytes 日志字符串
======== ============ ========= ======================

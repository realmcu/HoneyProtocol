# 3.8 控制命令 (command id 0x07)

L2 版本号：**0**

| Key    | 定义             | 方向      | Value                    |
|--------|------------------|-----------|--------------------------|
| `0x01` | 拍照控制         | 设备→手机 | 空                       |
| `0x02` | 单击控制         | 设备→手机 | 空                       |
| `0x03` | 双击控制         | 设备→手机 | 空                       |
| `0x11` | 相机应用状态请求 | 手机→设备 | `0x00`=前台；`0x01`=后台 |

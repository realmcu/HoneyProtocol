3.5 提醒命令 (command id 0x04)
==============================

.. warning:: 规范版本

   Excel 已将本命令重构为通知命令，并合并旧 ``0x04/0x07`` 的实时交互。新规范见 `0x04 通知命令 <../protocol/0x04-notification.html>`__；本页仅描述旧实现。

L2 版本号：\ **0**

======== ========== ========= =====
Key      定义       方向      Value
======== ========== ========= =====
``0x01`` 来电提醒   手机→设备 空
``0x02`` 来电已接听 手机→设备 空
``0x03`` 来电已拒接 手机→设备 空
======== ========== ========= =====

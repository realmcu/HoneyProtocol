附录：关键数据结构速查
======================

L1 Header 字节布局（Big-Endian）
--------------------------------

==== ===== ======================
Byte Bit   字段
==== ===== ======================
0    [7:0] Magic = ``0xAB``
1    [7:6] Reserve
1    [5]   ERR flag（1 = 出错）
1    [4]   ACK flag（1 = ACK 包）
1    [3:0] Version（当前 = 0）
2    [7:0] Payload length 高字节
3    [7:0] Payload length 低字节
4    [7:0] CRC16 高字节
5    [7:0] CRC16 低字节
6    [7:0] Sequence ID 高字节
7    [7:0] Sequence ID 低字节
==== ===== ======================

CRC16 计算范围
--------------

算法 **CRC-16/ARC**\ ：多项式 ``0x8005``\ （反射 ``0xA001``\ ），初值 ``0x0000``\ ，输入/输出均反射（refin=refout=true），无末异或（xorout=0）。\ **仅覆盖 Payload**\ ，不含 Header。空 payload（ACK 包）的 CRC 为初值 ``0x0000``\ 。自检：ASCII ``"123456789"`` → ``0xBB3D``\ 。

--------------------------------

==== ===== ==========
Byte Bit   字段
==== ===== ==========
0    [7:0] Command ID
1    [7:4] Version
1    [3:0] Reserve
